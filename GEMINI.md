# Gemini CLI agent instructions

Read and follow `AGENTS.md` (canonical project instructions; read order: README.md, RULES.md, PARTS.md).

For ANY interface, page, website, visual design, component or frontend work read `design-factory/AGENTS.md` and `design-factory/WORKFLOW.md` before changing source. Use `design-factory/core/` and `design-factory/reference/` for locally runnable design examples. Browser screenshots and RTL/LTR responsive verification are required before a visual release claim. Never claim to have inspected screenshots you have not actually viewed.

For motion, creative iconography, layered landing pages, WebGL or code-driven video, follow `design-factory/CREATIVE_AGENT_PLAYBOOK.md` and `design-factory/creative-recipes/`. Prefer the offline `creative-effects.css` and `creative-primitives.js`; test reduced motion, fallback and real browser frames. Video export goes through the owner's existing Animation Studio; never imply references are production dependencies.
