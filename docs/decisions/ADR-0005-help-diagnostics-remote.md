# ADR-0005 • Help is a core part of every product; hidden diagnostics

- **Date:** 2026-10-08 • **Status:** ACCEPTED by owner (session request).

## Decisions
1. **Help is core** ([HELP_AND_GUIDANCE_STANDARD.md](../HELP_AND_GUIDANCE_STANDARD.md)): guides, "Guide me" coach, "Solve a problem"
   section with edge cases, questions, contact support, "?" on every page. Grown with every release and every ticket.
2. **Help language:** polished Egyptian Arabic, understood by a 12-year-old, respectful and professional.
3. **No welcome slideshow** on first sign-in in any product; a tour may exist only as an opt-in button inside Help.
4. **Product defaults:** light theme ("daylight") and the system font, unless a product records another choice.
5. **Hidden diagnostics probe** in every product ([DIAGNOSTICS_AND_REMOTE_FIX.md](../DIAGNOSTICS_AND_REMOTE_FIX.md)), started only by
   the vendor under an open customer support window; fixes ship as signed updates.
6. Remote support keeps the ADR-0002 rules (customer-initiated, time-boxed, visible, revocable, audited).
