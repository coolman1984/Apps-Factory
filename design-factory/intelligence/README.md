# Design Intelligence Engine v1
This is an offline source-routing and validation CLI, not a web scraper or a visual redesign agent.

Run:
```
node --test design-factory/intelligence/engine.test.mjs
node design-factory/intelligence/engine.mjs pos
node design-factory/intelligence/engine.mjs website
node design-factory/intelligence/engine.mjs video
```

The registry contains inspiration references only. Never copy protected assets or claim to have visited websites. Inspora is disabled pending verification. The CLI produces structured reference recommendations and explicit limitations; a browser-capable implementation and screenshot verification are still separate work.

For visual work follow `design-factory/AGENTS.md`, `DESIGN.md`, `WORKFLOW.md` and `QA_CHECKLIST.md`. Preserve offline behavior, AR RTL, EN LTR, accessibility, reduced-motion and existing business logic. Attach real browser evidence to release PRs.
