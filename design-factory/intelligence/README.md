# Design Intelligence Engine: activated source registry (v1)

This module **activates a versioned reference registry and offline validation command**, not a live scraping engine or an automatic redesign agent. Run `node design-factory/intelligence/audit.mjs` from the repository root. No runtime dependencies, network, credentials or third-party assets.

## Design-agent execution protocol
1. Read `../AGENTS.md`, `../DESIGN_CONSTITUTION.md`, `../DESIGN.md`, `../WORKFLOW.md`, `../QA_CHECKLIST.md` and the product's own design instructions.
2. Select **sector-relevant** reference sources from `sources.json`. Treat each as *inspiration only*. Do not reproduce layouts, logos, screenshots or videos as product assets without permission.
3. If browser access exists, inspect references visually and record dated evidence, interaction patterns, and licensing constraints. If not, mark external review UNVERIFIED. Never imply automatic crawling.
4. For a supplied local app, capture its real baseline screenshots (desktop/tablet/mobile, AR/EN, light/dark), list user journeys, and identify three actionable usability defects.
5. Produce a design brief: user/job, hierarchy, spacing, typography, interaction/motion grammar, acceptance criteria, performance and offline budgets.
6. Implement one complete slice in the app's existing stack; preserve accounting, inventory, permissions, audit and data contracts.
7. Run real browser screenshots and workflow checks, compare before/after, and fix visual regressions. Reduced-motion and keyboard operation are mandatory.
8. PR changes only with explicit evidence. Missing browser or network checks are UNVERIFIED and block claims of full activation.

## Reference routing
- Mobbin: real app flows, POS navigation and dense forms
- 60fps: interaction grammar, duration and easing, reduced-motion alternatives
- Landbook: marketing layouts, visual hierarchy and typography
- Reelfolio: presentation and showreel storytelling
- Movez: iterative motion-review workflow
- Inspora: disabled until availability and usage rights are independently verified
